llm-discovery CLI · Python 3.12 · MIT

Finds the best free coding LLMs across providers and wires them into your gateway.

llm-discovery scans the providers you configure, judges every model for coding relevance, and exports a curated keep-list as gateway combos. One CLI, from discovery to a live route.

The problem

Free coding models are everywhere. Finding them is the work. Which models are free this week, which of those can actually write code, and which are worth routing to — that answer lives across a dozen model lists, pricing pages, and benchmark sites, and it changes constantly.

  • Free tiers are buried. Provider model lists don't say which entries are free, and the tags move without notice.
  • A model list is not a shortlist. Names and sizes say nothing about coding quality.
  • Wiring the survivors is manual. Copying keepers into a gateway drifts the moment a provider updates.

How it works

  1. Configure

    List your providers in config/providers.yaml: a name, a base URL, and the env var holding its key.

  2. Discover

    Enumerate every provider's /models endpoint and drop non-free entries before spending a single judge token.

  3. Judge

    Resolve each model against models.dev and Artificial Analysis, then score coding relevance with an LLM judge.

  4. Build

    Keep what passes the Accurate-Enough Gate, cache it for 14 days, and re-judge only what changed.

  5. Export

    Partition keepers into flash / max / contributor_free combos and apply them to your gateway.

What comes out

A real excerpt from the export payload: one combo per non-empty tier, keep-all, auto strategy.

Run it

llm-discovery is a CLI, and it is not a gateway. It finds the models and configures the OmniRoute gateway you already run — so the last step needs a reachable gateway and a management key. Everything before that is local.
