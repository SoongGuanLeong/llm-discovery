llm-discovery CLI · Python 3.12 · MIT
Free models, judged for code

Finds the best free coding LLMs across providers and wires them into your gateway.

It scans the providers you configure, judges every model for coding relevance, and exports a curated keep-list as gateway combos. One CLI, from discovery to a live route.

The problem

Free coding models are everywhere. Finding them is the work — which are free this week, which can actually write code, and which are worth routing to. That answer lives across a dozen model lists, pricing pages, and benchmark sites, and it changes constantly.

Free tiers are buried

Provider model lists don't say which entries are free, and the tags move without notice.

A list is not a shortlist

Names and sizes say nothing about coding quality. A big catalogue is not a recommendation.

Wiring it up is manual

Copying keepers into a gateway drifts the moment a provider updates its roster.

How it works

Five steps, one command chain.

1Configureproviders.yaml
2Discover/models, free-only
3Judgecatalogs + LLM
4Buildgate + 14-day cache
5Exporttier combos

Configure

List your providers in config/providers.yaml: a name, a base URL, and the env var holding its key.

Discover & judge

Enumerate each provider's /models, drop non-free entries, resolve against models.dev and Artificial Analysis, then score coding relevance with an LLM judge.

Build & export

Keep what passes the Accurate-Enough Gate, cache it for 14 days, then partition keepers into flash / max / contributor_free combos.

What comes out

Two of the three combos from the export payload (the max combo is omitted). The payload holds one keep-all combo per non-empty tier, auto strategy.

omniroute_combos.example.json
[
  {
    "name": "contributor_free",
    "strategy": "auto",
    "models": [
      { "provider": "bazaarlink", "model": "auto:free" },
      { "provider": "groq", "model": "contributor-model-free" }
    ]
  },
  {
    "name": "flash",
    "strategy": "auto",
    "models": [
      { "provider": "groq", "model": "llama-3.3-70b-versatile" }
    ]
  }
]

Source: data/derived/examples/omniroute_combos.example.json.

Run it

llm-discovery is a CLI, and it is not a gateway. It finds the models and configures the OmniRoute gateway you already run — so the last step needs a reachable gateway and a management key.

Everything before that is local. The 5-minute Golden Path in the README walks the whole chain: doctor, set-key, providers list, discover, build, export.
