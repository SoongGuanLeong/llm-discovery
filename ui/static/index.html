OmniRoute — local AI gateway

Install (npm, any OS):
npm install -g omniroute        # or: pnpm add -g omniroute@latest --allow-build=better-sqlite3
omniroute                        # boots gateway + dashboard on http://localhost:20128
Verify:
curl -s http://localhost:20128/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}' | jq
Docker alternative:
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data diegosouzapw/omniroute:latest
Source: github.com/diegosouzapw/OmniRoute · npmjs.com/package/omniroute · hub.docker.com/r/diegosouzapw/omniroute

Infisical — secrets

Install:
brew install infisical/get-cli/infisical
Auth & run:
infisical login
infisical run -- .venv/bin/python scripts/discover.py groq --all
infisical export --projectId "$LLM_SHARED_PROJECT_ID" --env dev --format json | jq length
Cloud: app.infisical.com · Self-hosted: set INFISICAL_DOMAIN
Docs: infisical.com/docs/cli/overview · infisical.com/docs/cli/usage · infisical.com/docs/self-hosting/overview
Offline: BRAVE_API_KEY optional -> DuckDuckGo used. DISABLE_WEB_SEARCH=1 = offline (no web calls). Discovery + --dry-run work offline.
Links: github.com/diegosouzapw/OmniRoute · npmjs.com/package/omniroute · infisical.com/docs/cli/overview · infisical.com/docs/cli/usage · infisical.com/docs/self-hosting/overview
