llm-discovery CLI · Python 3.12 · MIT

Discovery for free coding models

Find the free coding models worth routing to.

Finds the best free coding LLMs across providers and wires them into your gateway. It scans the providers you configure, judges every model for coding relevance, and exports a curated keep-list as gateway combos.

Read the Golden Path View the source

The problem

Free coding models are everywhere. Finding them is the work. Which models are free this week, which of those can actually write code, and which are worth routing to — that answer lives across a dozen model lists, pricing pages, and benchmark sites, and it changes constantly.

  • free tiers Provider model lists don't say which entries are free, and the tags move without notice.
  • lists vs shortlists Names and sizes say nothing about coding quality. A big catalogue is not a recommendation.
  • manual wiring Copying keepers into a gateway drifts the moment a provider updates its roster.

How it works

01Configureproviders.yaml
02Discover/models, free-only
03Judgecatalogs + LLM
04Buildgate + 14-day cache
05Exporttier combos

The pipeline

  1. 01Configure. List your providers in config/providers.yaml: a name, a base URL, and the env var holding its key.
  2. 02Discover. Enumerate every provider's /models endpoint and drop non-free entries before spending a single judge token.
  3. 03Judge. Resolve each model against models.dev and Artificial Analysis, then score coding relevance with an LLM judge.
  4. 04Build. Keep what passes the Accurate-Enough Gate, cache it for 14 days, and re-judge only what changed.
  5. 05Export. Partition keepers into flash / max / contributor_free combos and apply them to your gateway.

What comes out

Two of the three combos from the export payload (the max combo is omitted). The payload holds one keep-all combo per non-empty tier, auto strategy.

[
  {
    "name": "contributor_free",
    "strategy": "auto",
    "models": [
      { "provider": "bazaarlink", "model": "auto:free" },
      { "provider": "groq", "model": "contributor-model-free" }
    ]
  },
  {
    "name": "flash",
    "strategy": "auto",
    "models": [
      { "provider": "groq", "model": "llama-3.3-70b-versatile" }
    ]
  }
]

Source: data/derived/examples/omniroute_combos.example.json.

Run it

llm-discovery is a CLI, and it is not a gateway. It finds the models and configures the OmniRoute gateway you already run — so the last step needs a reachable gateway and a management key. Everything before that is local.
